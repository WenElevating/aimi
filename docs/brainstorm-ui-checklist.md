## 已定决策（随对话追加）
- 双主题策略：浅色系=「冷静高级」，暗色系=「神秘极客」，同一设计系统的两种人格〔对话 2026-10-17〕
- 首轮三案（电光青/珊瑚橙/量子紫）全部被否，要求调研主流 agent 桌面端吸取灵感〔对话 2026-10-17〕
- 调研结论（getdesign.md 公开拆解 + openai.com/brand）：六参照共同 DNA=表面阶梯做纵深、发丝线替代阴影、品牌电压只开一处、等宽字体=机器在说话、语义色只管状态。Claude=暖纸+珊瑚+衬线标题；OpenAI=近零彩色+黑电压句号；Cursor=奶油+橙电压+杂志排印；Linear=午夜石墨四级阶梯+薰衣草紫+Inter/-0.022em+Berkeley Mono；Zed=深黑+鲜艳语法色仅限机器说话处；Gemini=Material 3 动态取色（只借大圆角）
- Codex app（openai.com，2026.2 发布，macOS/Windows）=「agent 指挥台」：管理多 agent、并行、按项目组织线程——与 aimi 同物种，是最直接参照
- 排版修订 v2（用户反馈：色彩可以，但文字堆积太多；向 Claude Code + Codex 取经）：
  1. 列表行替代卡片盒（Claude Code /resume 的手法）：发丝线分隔
  2. 每行最多两行字：主题 + 单行摘要；tokens/价格/时长藏进详情页（Codex：状态词即内容）
